# fork-updates-r10o — доставка вложений и Dante

## Где работать

Изолированный клон `chaskiq-fork-updates-r10o` от актуального main.
Спека коммитится в `docs/specs/fork-updates-r10o.md`. Живой checkout только читать.
git pull в клоне не делать; push в origin запрещён, работу заберёт постановщик через `git fetch` из клона.
Все запуски проекта через Docker под своим UID/GID с существующим образом
и кэшем вехи. Никаких реальных запросов к провайдерам.

## Что проверено вживую

RuboCop без наследования todo выявил ровно восемь нарушений:
`BlockManager.deliver_attachments` AbcSize 53.2, Cyc 27, Perceived 30,
MethodLength 54; `Dante::Renderer#convert_node_to_element` AbcSize 54.44,
Cyc 15, MethodLength 43; `Dante::Migrator.migrate_bot_tasks` AbcSize 32.88.
Существуют тесты BlockManager, Dante renderer и golden-выходы каналов.
Из тел методов подтверждены порядок методов, возвращаемые значения, операции
с каждой записью и расположение rescue. Новые сценарии подтвердить на BASE.

## План

1. Проверь существующие спеки для этих входов. Перед кодом добавь
   поведенческие примеры по реальным пробелам:
   - BlockManager. Фиксируй пропуск неподдерживаемого URL и повторы как
     числом, так и по исходным индексам. Сохрани порядок вызовов отправки
     и callback, первую успешную реакцию, возвращаемый отказ, резервный
     текст, остаточную подпись и ветку без тела. Прогони уже имеющиеся
     случаи при исключении транспорта и callback. Сверь golden Slack и
     WhatsApp, а также Telegram/Twitter после R10m.
   - Renderer. Проверяй точные строки для HTML-узлов с вложенным текстом,
     headings с/без attrs, неизвестного типа, делителя и media-диспетча.
     Сохрани разные наборы аргументов конструкторов media (некоторые
     получают domain). Сохрани пробелы HTML и логи, приоритет marks и
     поведение заданного, но nil уровня heading.
   - Migrator. Проверяй записи двух приложений, отсутствие id/paths,
     смешанные шаги с несколькими сообщениями, сохранение полей settings
     вокруг paths и продолжение после исключения преобразования.
   Сначала коммит спек, зелёных на BASE.
2. Разбей три метода, сохрани их публичные сигнатуры и видимость других
   методов. Для BlockManager обработка состояния и выбор результата могут
   идти отдельными методами. Сохрани различие между успехом callback и
   транспорта, очередь отказов, значение результата в ensure, отложенный
   повторный raise и LocalJumpError при отсутствующем блоке, если BASE его
   выдаёт. Для Renderer допустимы таблицы типов с приватными помощниками.
   Для Migrator вынеси обработку одной записи и шага, сохрани область
   rescue на запись и обновление через update_column.
3. Удали ровно восемь относящихся к вехе строк todo (4 BlockManager,
   3 Renderer, 1 Migrator). Добавь датированную запись в CHANGELOG.
   Четыре смысловых коммита с заголовками до 50 символов и без трейлеров.
4. Запусти целевые спеки на BASE и финале, строгий RuboCop, полный RSpec
   и замер всего бэклога без todo. Ожидается точное снижение на восемь,
   без роста по каждой паре коп/файл. Дай по одной наблюдаемой мутации
   каждого целевого метода для отдельного прогона постановщиком.

## Не трогать

Пути в диффе: три целевых файла, добавленные поведенческие спеки, todo и
CHANGELOG. Соседние провайдеры, конвертер, фикстуры прежних вех, зависимости,
контейнеры и конфигурация вне вехи. Запрещены rubocop-директивы, пропуски
новых примеров и чтение исходников из спек.

## Критерии приёмки

- **AC-001** — полный RSpec в Docker.
  `bash -c 'CI_LOCAL_CACHE=$HOME/.cache/chaskiq-r10o-ci bin/ci-local --only rspec'`
- **AC-002** — строгий RuboCop.
  `bash -c 'CI_LOCAL_CACHE=$HOME/.cache/chaskiq-r10o-ci bin/ci-local --only rubocop'`
- **AC-003** — тесты проверяют поведение.
  `bash -c 'B=$(git merge-base HEAD @{u}) && python3 -I docs/specs/fork-updates-r10l-probes/source_scan.py "$B"'`
- **AC-004** — пробельная проверка и чистое дерево.
  `bash -c 'B=$(git merge-base HEAD @{u}) && git diff --check "$B"..HEAD && test -z "$(git status --porcelain --untracked-files=all -- . ":(exclude)report.json" ":(exclude)report-blocked.md")"'`

## Авторевью

Запусти agy через `review_run.sh` над конечным продуктовым диффом. Сохрани
результат или точную причину недоступности.

### Контракт отчёта

В корне untracked `report.json`, четыре записи `criteria` с `id`, `command`
дословно, `status`, `rc`, `note`. Отдельно SHA, executor, вывод целевых спек
BASE и дерева, замер без todo и вердикт ревью.

## Контракт на невыполнимое

Сохрани точный блокер и готовые коммиты. Ошибки ожиданий сверить на BASE,
исправить фикстуры и продолжить. Критерии и область не подменять.
